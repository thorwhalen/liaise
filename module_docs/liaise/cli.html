liaise.cli

The liaise command-line interface.

One SSOT list of plain functions (_dispatch_funcs), dispatched with cw (see python-dispatching). Each function takes flat, serializable arguments and prints its own output — nothing here returns a live object across the CLI boundary. The list grows as later issues add setup, poll, run, status and schedule.

liaise.cli.partner_list(*, root: str | None = None) → str[source]

Print every configured partner’s slug and display name.

liaise.cli.partner_show(slug: str, *, root: str | None = None) → str[source]

Print the resolved config for partner slug, defaults applied.

liaise.cli.poll(*, root: str | None = None, partner: str | None = None, gh: GitHub | None = None) → str[source]

Report each partner’s open issues, their readiness, and a countdown. Changes nothing.

liaise.cli.run(*, root: str | None = None, once: bool = False, dry_run: bool = False, partner: str | None = None, gh: GitHub | None = None, dispatcher: Dispatcher | None = None, store: MutableMapping | None = None) → str[source]

Intake, label, dispatch ready issues, batch-deploy, reconcile.

Prints where dispatch logs go (log_dir), then the plan. –dry-run prints the same and changes nothing. Without –once, keeps running one pass after another — the scheduled job always passes –once (see liaise schedule install); this is for a foreground, manual “keep watching” run.

liaise.cli.schedule_install(*, root: str | None = None, interval_minutes: int = 2, extra_env_vars: Sequence[str] | None = None) → str[source]

Install the scheduled liaise run –once job (launchd on macOS, systemd on Linux).

extra_env_vars: names of additional environment variables (beyond PATH, HOME, and the configured ntfy topic variable) a partner’s dispatch command needs snapshotted into the job’s environment — A.7 (“whatever the dispatch command needs”), which had no way to reach the scheduler from the CLI (M-4).

liaise.cli.schedule_status_cmd() → str[source]

Whether the scheduled job is installed.

liaise.cli.schedule_uninstall() → str[source]

Remove the scheduled job. Idempotent.

liaise.cli.setup(slug: str, *, root: str | None = None, gh: GitHub | None = None) → str[source]

Create partner slug’s label and every state label in their repo. Idempotent.

liaise.cli.status(*, root: str | None = None, gh: GitHub | None = None, store: MutableMapping | None = None) → str[source]

When the last run started and ended (and whether it is still running or was interrupted), today’s dispatches per partner, and anything needing the owner.
