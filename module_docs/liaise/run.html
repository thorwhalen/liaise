liaise.run

The run loop (A.5 batching, A.7): intake, label, dispatch, batch-deploy, reconcile.

liaise poll (intake.py + cli.py) only reports. This module is where liaise acts — always behind –dry-run, which prints the same plan without calling any mutating GitHub method.

property state: str

never, finished, running or interrupted.

A pass that started later than the last one ended is running — unless the lock was checked and no live process holds it. Then the pass was killed (a SIGTERM from launchctl bootout, a shutdown) before it could stamp its end: interrupted, since a job that stopped must not read as one that is busy.

liaise.run.run_once(gh: ~liaise.github.GitHub, dispatcher: ~liaise.dispatch.Dispatcher, store: ~typing.MutableMapping, config: ~liaise.config.Config, *, partner: str | None = None, dry_run: bool = False, notify_fn: ~typing.Callable[[...], bool] = <function notify>, log_dir: ~pathlib.Path | None = None, now: ~datetime.datetime | None = None) → RunReport[source]

One pass: intake new issues, dispatch ready ones, batch-deploy landed ones, nudge stale deployed issues.

dry_run prints the same plan without calling any mutating GitHub method and without stamping the run — it changes nothing, the same promise liaise poll makes. Otherwise the store gets run_started_at when the pass begins and run_ended_at when it stops, even by raising (see run_stamps()). Not re-entrant with itself (L-3): a real scheduled invocation takes a lock in config.global_.state_dir so a manual liaise run alongside the timer can’t double-dispatch.

log_dir defaults to config.global_.log_dir_path; each dispatch’s log, whose path the agent’s prompt names, is written there.

liaise.run.run_stamps(store: MutableMapping, *, lock_path: Path | None = None) → RunStamps[source]

The run stamps run_once keeps in store. Pass lock_path (see run_lock_path()) to tell a running pass from a killed one.

A store last written by 0.0.3 or earlier holds only last_run — the start of a pass that had already finished — read here as a run that started and ended then.
