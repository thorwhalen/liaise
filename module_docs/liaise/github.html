liaise.github

The GitHub seam: one protocol, two implementations.

liaise never holds a token. All real access goes through the gh CLI, whose auth belongs to the machine (GhCli). Every other module in this package talks to GitHub, never to gh or subprocess directly, so tests use FakeGitHub — in-memory, no network, no real repo.
